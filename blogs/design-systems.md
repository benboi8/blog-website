# Design Systems Are Shared Language

A design system is often introduced as a collection of components. In practice, its most valuable contribution is shared language.

## What belongs in the system?

1. Foundations such as type, colour, spacing, and elevation.
2. Reusable components with documented states.
3. Content guidance for labels and error messages.
4. Accessibility requirements.

> Consistency should reduce cognitive load, not remove character.

| Decision | Why it matters |
| --- | --- |
| Visible focus | Keyboard users can track interaction |
| Clear labels | Screen readers expose useful actions |
| Sufficient contrast | Text remains readable |

Accessibility should be treated as the default rather than a later compliance pass.
